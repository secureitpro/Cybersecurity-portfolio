Project Overview

I completed the Cloud Computing Fundamentals room on TryHackMe as part of my cybersecurity training.

This room introduced cloud computing and how organizations access computing resources and services over the internet.

Topics Covered

* Introduction to cloud computing
* Cloud service models: IaaS, PaaS, and SaaS
* Public, private, and hybrid clouds
* Benefits of cloud computing
* Cloud infrastructure and security fundamentals

Skills and Knowledge Gained

* Understanding the purpose of cloud computing
* Recognizing different cloud service models
* Learning how cloud resources support organizations
* Building foundational knowledge of cloud environments
* Understanding why cloud security matters

What I Learned

I learned how cloud computing provides access to computing resources without requiring organizations to manage all their infrastructure locally.

Understanding cloud environments supports my SOC Analyst career goal because security teams monitor cloud services, investigate suspicious activity, and protect organizational data.
