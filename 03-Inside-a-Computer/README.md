Platform: TryHackMe

Status: Completed

Career Goal: SOC Analyst

Project Overview

I completed the Inside a Computer room on TryHackMe as part of my cybersecurity learning journey.

This room introduced the main components inside a computer and their roles in how a computer operates.

Topics Covered

* Central Processing Unit (CPU)
* Random Access Memory (RAM)
* Computer storage
* Motherboard and internal hardware components
* How computer components work together

Skills and Knowledge Gained

* Understanding basic computer hardware
* Recognizing the purpose of key internal components
* Learning the difference between memory and storage
* Building foundational knowledge for troubleshooting and cybersecurity

What I Learned

This room helped me understand how computer hardware supports operating systems and applications.

Understanding these components is useful for my goal of becoming a SOC Analyst because security professionals need foundational knowledge of the systems they monitor and protect.
